Hướng dẫn khởi chạy:

1. Trên máy Mac, chạy đường hầm:

cloudflared tunnel --url http://localhost:8642

2. Lấy link Cloudflare https://... dán vào ô API Base URL ở trên.

Mọi tin nhắn của sếp sẽ được mã hóa và chuyển tiếp an toàn thông qua Cloudflare Tunnel trực tiếp về máy Mac tại nhà.
